## Featured project

### 🚌 RoutePulse: Berlin-Brandenburg Mobility Analytics

RoutePulse is an end-to-end public transport data project built from VBB GTFS Static and GTFS-Realtime data.

I collected 777 realtime snapshots containing approximately 94.8 million raw stop-time observations. I then developed a tested process that reduced the repeated feed messages to 1.76 million distinct stop visits for analysis.

The project includes:

- Python data collection and validation
- Protocol Buffer decoding
- Typed Parquet conversion
- SHA-256 checksums and audit records
- Amazon S3 storage
- Snowflake data modelling
- SQL validation worksheets
- Geographic and timetable enrichment
- Streamlit dashboard development
- Interactive transport maps
- Timing-data quality analysis
- Early, near-schedule and late-service classifications
- 37 Python unit tests
- Validation of dashboard totals against the analytical event table

The dashboard lets users explore Berlin and Brandenburg by observed stop area, transport mode, station, line and time.

A major part of the project was improving the language used in the analysis. Instead of assuming that every timing value represents a delay, RoutePulse separates early, near-schedule, moderately late, seriously late and unavailable timing information.

## How I work

I prefer projects where the reasoning is visible, not only the final chart or interface.

My usual approach is to:

1. Define the business or user question.
2. Inspect the available data and its limitations.
3. Create clear definitions for every metric.
4. Preserve the original evidence before transforming it.
5. Separate collection, storage, modelling and presentation.
6. Test failure cases as well as successful cases.
7. Reconcile dashboard totals with the underlying data.
8. Explain technical findings in language a non-technical stakeholder can understand.
9. State what the analysis supports and what it cannot prove.

I care about details such as denominators, missing values, duplicate observations, sample sizes and unclear labels because these details can completely change how a result is interpreted.
